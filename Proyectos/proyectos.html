Proyecto Ahorro Energia
Ahorro Energia Software
HTML CSS

Mi proyecto es una página web informativa dedicada al ahorro de energía en el desarrollo de software. El sitio incluye secciones con información educativa, consejos prácticos, ejemplos visuales y estadísticas que muestran cómo un software optimizado puede reducir el consumo eléctrico. El objetivo es concienciar a los usuarios y programadores sobre la importancia de crear programas más eficientes, promoviendo así la sostenibilidad y el cuidado del medio ambiente.

Proyecto StartupTech
StartupTech
JS HTML CSS

Proyecto app biblioteca
Biblioteca ISTL
App Inventor

Mi proyecto es una aplicación móvil desarrollada en App Inventor que permite gestionar una biblioteca de forma sencilla y accesible. La app incluye funciones para registrar, visualizar y eliminar libros, además de buscar por filtros y mostrar imágenes y descripciones. El objetivo es facilitar la organización y consulta de libros desde un teléfono móvil, promoviendo el uso de herramientas tecnológicas para la gestión educativa y cultural.

Proyecto Juego de Naves
NAV GUN
Scracht

Mi proyecto es un juego creado en Scratch donde el jugador controla una nave espacial que debe eliminar a los alienígenas invasores. El juego incluye animaciones, sonidos y un sistema de puntuación que aumenta con cada enemigo derrotado. Proyecto app Dados
DADO SUPREMO
Kotlin XML Android

Mi proyecto es una aplicación móvil desarrollada en Android Studio que simula un juego de dados interactivo. El usuario puede lanzar el dado, obtener resultados aleatorios y competir por el número más alto. La app incluye botones, imágenes dinámicas y mensajes de resultado, ofreciendo una experiencia simple pero divertida. El objetivo es entretenimiento y aprendizaje, demostrando cómo se pueden crear juegos funcionales con programación móvil.
Proyecto Juego Retro
DUCK HUNT
Scratch

Mi proyecto es un juego retro creado en Scratch inspirado en el clásico Duck Hunt. El jugador utiliza el cursor como mira para disparar a los patos que aparecen volando por la pantalla, sumando puntos por cada acierto. El juego incluye animaciones, efectos de sonido, conteo de puntuación y niveles de dificultad, ofreciendo una experiencia divertida y nostálgica. El objetivo es recrear un clásico arcade mientras se aplican conceptos de programación y diseño de juegos en Scratch.
